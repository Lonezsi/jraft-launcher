World generation

New terrain, biomes and structures

Terralith adds new overworld biomes. Tectonic changes the shape of the terrain: higher mountain ranges, deeper valleys, rivers and canyons. Incendium replaces Nether generation and Nullscape replaces the End. Structory adds small structures such as ruins and towers. Better Trees changes tree shapes.

The JRAFT server generates its world with the same mods.

Far terrain

Distant Horizons

Distant Horizons draws terrain beyond the normal render distance at lower detail. How far depends on the graphics preset: 64 to 256 chunks.

Animation and sound

Mobs, players and sounds

Animation: Fresh Animations animates mobs, using Entity Model Features and Entity Texture Features. Not Enough Animations and First-person Model add player animations and show your body in first person. 3D Skin Layers draws the outer skin layer in 3D. Camera Overhaul tilts the camera when you turn. Elytra Physics, Cool Elytra Roll and Elytra Trails change elytra flight.

Sound: Presence Footsteps plays footsteps that match the block. Ambient Sounds adds background sound per biome. Sound Physics Remastered adds echo and muffles sound through walls. Drip Sounds, Entity Sound Features and Sounds add more sounds.

Grass, leaves and plants

Plant packs, combined

Grassrise adds grass blades on top of grass blocks. Simple Grass Flowers adds clovers, small flowers and stones to grass, podzol and mycelium. Os' Colorful Grasses, Simple Foliage and Grass Clovers add variants of short and tall grass. Bushier Bushes makes bushes and shrubs 3D. Better Leaves gives leaves a bushy outline and Os' Colorful Leaves recolours them. Fresh Flowers and Plants replaces flowers and saplings with 3D models.

Several of these packs change the same blocks, and normally only the one on top would show. JRAFT Grass and JRAFT Leaves, two packs made for JRAFT, combine them so all of them show at the same time.

The launcher

What the JRAFT launcher does

Open it every time you play. It checks everything below, then starts the game.

  • Joins the server

    Starts the game on the JRAFT server through its own tunnel, voice chat included, and puts JRAFT at the top of the server list.

  • Uses Prism Launcher

    Uses your Prism Launcher if you have one, otherwise a portable copy it keeps updated. Adds a JRAFT instance.

  • Brings Java 25

    Downloaded for JRAFT only. Memory for the game is set from your RAM: 2.5 to 6 GB.

  • Keeps the pack up to date

    Downloads mods, resource packs and shaders, checks each file's sha512, and removes files that have left the pack. Files you added stay.

  • Keeps your settings

    Default configs are copied only when missing, so your keybinds and changes stay after updates.

  • Checks your own mods

    A mod you added that can't run on this Minecraft version is moved to mods-disabled, not deleted.

  • Orders the resource packs

    Turns the pack's 37 resource packs on in the order they need. Packs you turned on yourself stay on.

  • Fixes packs

    Removes the broken shield and tool models from Fresh Flowers and Plants and Fresh Food, and adds JRAFT Grass and JRAFT Leaves.

  • Picks graphics settings

    Reads your graphics card and applies one of four presets. Your own changes are kept afterwards.

  • Picks the account

    With several Microsoft accounts in Prism it asks which one to play on, with a Don't ask again option.

  • Updates itself

    On Windows and Linux it installs each new release when it starts. On a Mac the log says when one is available.

  • Shows a log

    Show log lists every step. Copy log copies it so you can send it when something goes wrong.

Shader choice

On the medium preset and higher, the first time it runs the launcher shows both shaders with a screenshot of the same cave and asks which to use. The choice is saved and not asked again.

Install

Getting started

You need Minecraft Java Edition on a Microsoft account.

  1. Download

    Pick your system below. On a Mac, unzip it and move JRAFT to Applications.

  2. Open it

    It sets up Prism, Java and the pack. Open it every time you play to get updates.

  3. Sign in

    The first time, sign in with your Microsoft account in Prism's window.

  4. Play

    The game starts and joins the JRAFT server.
